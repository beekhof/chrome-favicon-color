Favicon Color Tint

Configure color tints for favicons based on URL patterns

Add New Rule

Enter a simple text pattern (e.g., github.com) or a regular expression wrapped in slashes (e.g., /github\.com/). The pattern will be matched against the full URL.

Examples:

  • github.com - Matches any URL containing "github.com"
  • /^https:\/\/github\.com/ - Matches URLs starting with "https://github.com"
  • localhost - Matches local development sites
  • /\.(dev|test)\./ - Matches .dev or .test domains
